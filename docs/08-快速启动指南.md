# 快速启动指南

面向第一次把本仓库跑起来的开发者。业务约束在 `docs/04-业务规则与验收用例.md`，部署细节在 `docs/05-部署手册.md`。

## 1. 准备

- Node.js 18.18 或更高
- Docker Desktop（Compose v2）
- 端口 80、3000、3306 没被占用

```bash
git clone <仓库地址>
cd shangmeng
```

## 2. 配置环境变量

```bash
cp .env.example .env
cp server/.env.example server/.env
```

至少改这几项，不要把真实密钥提交进 git：

| 变量 | 作用 |
|---|---|
| `MYSQL_ROOT_PASSWORD` / `MYSQL_PASSWORD` | 数据库口令，两处保持一致 |
| `JWT_SECRET` | 后台登录令牌 |
| `WX_MODE` | 本地填 `mock`。生产必须是 `real`，并提供 `WX_APPID` / `WX_SECRET` |
| `LAYA_SERVICE_URL` | 默认 `http://laya:8765` |
| `DEEPSEEK_API_KEY` | 只放在运行中的容器环境，不写入仓库 |

`WX_MODE=mock` 时，H5 登录页会标明「测试环境专用」。

## 3. 一键启动

镜像构建请关掉 BuildKit（当前环境拉取 `node:22-alpine` 元数据会失败）：

```powershell
$env:DOCKER_BUILDKIT = "0"
docker compose up -d --build
```

首次启动后写入演示数据：

```powershell
docker compose exec -T server npm run prisma:seed
```

| 入口 | 地址 |
|---|---|
| 管理后台 | http://localhost |
| 接口文档 | http://localhost/api/docs |
| C 端登录 | http://localhost/h5/login |

演示账号密码都是 `Test@123456`：`admin`（主体）、`sub01`（城南，可发主体券）、`sub02`（城西，已有授权记录但角色不能发券）、`clerk01`（S-101 店员）、`platform`（平台）。

登录 `admin` 后，工作台应能看到星系图和近 7 天折线，通知铃铛有 3 条未读。

## 4. 跑测试

```powershell
npm run regression
```

这条命令会先 seed，再按 S1 到 S7 顺序跑 `docs/archive/test-scripts/`，任一失败即停，结束时再 seed 一次回到演示基线。

秒杀库存压测（10 人抢 5 张，再同时核销）：

```powershell
npm run e2e:flash
```

脚本结束会删掉自己造的用户和券模板。

只改后端、不重建镜像时，seed 读的是镜像里的 `prisma/seed.ts`。改过种子后要重新 `docker compose build server` 再 up。
