# S8 微信支付资质材料清单

S8（支付即积分）在商户资质审核通过前不开发、不联调。下面是向微信支付提交进件时要备齐的材料，先归档，不代表这些文件已经在仓库里。

## 主体资质

- 营业执照彩色扫描件（星链商盟主体，统一社会信用代码、名称、住所、经营范围、有效期清晰）
- 法人身份证正反面彩色扫描件
- 对公银行账户：开户许可证或基本存款账户信息（户名与营业执照一致）
- 经营场景说明：小程序 / H5 里「消费得积分、积分兑券、到店核销」的页面说明和截图

## 微信支付账号

- 商户号（mchid）申请表，超级管理员姓名、手机号、邮箱
- 已认证的微信小程序 AppID，并在商户平台把 AppID 绑定到该商户号
- APIv3 密钥、商户 API 证书（`apiclient_key.pem`）及证书序列号
- 支付结果通知 URL（本系统上线域名的 HTTPS 地址，上线前再定）
- 若走「支付即积分」：微信支付分账或支付成功回调的权限开通回执

## 与现有代码的衔接（审核通过后再做）

- `users.unionid` 已在库里，用来把支付用户和 C 端用户对上
- C 端登录目前是 `WX_MODE=mock` 的测试 code。生产必须改为 `WX_MODE=real`，并配置 `WX_APPID` / `WX_SECRET`
- 密钥只放运行环境，不提交 git

审核被拒或材料缺项时，补在本文件后面，不要提前写支付下单代码。
