3) Network 面板证明（全部真实打到 /api/v1/*）
================================================================================
A. 打开页面立即拉一次 + 60s 内无重复 + 60s tick 生效（单条命令内连续测量，无外部干扰）：
     t=5s  -> 1 次   GET /api/v1/notifications/unread-count   200   （首屏立即拉）
     t=50s -> 1 次                                                （60s 内无重复）
     t=70s -> 2 次                                                （60s 轮询 tick 生效）

B. 打开面板时单独拉列表（不复用未读数接口）：
     GET /api/v1/notifications?readStatus=UNREAD&page=1&pageSize=5   200

C. 切出页面（visibilityState=hidden）后停止请求：
     设 hidden 后  3s -> 0 次
     设 hidden 后 65s -> 0 次（跨过一个完整 60s tick，仍不请求）
     设 hidden 后 70s -> 0 次
     （实现：setInterval 每 60s tick 内先判 document.visibilityState !== 'visible' 直接 return）

D. 切回可见（距上次拉取 >60s）恰好补刷 1 次（无双 Fetch）：
     GET /api/v1/notifications/unread-count   200   -> 1 次
     节流阈值 60s：若切回时距上次拉取不足 60s 则不请求（避免来回切标签页打爆接口）

E. 全部已读链路：
     PATCH /api/v1/notifications/read-all   200   -> 徽标消失、面板空态、toast、工作台卡片同步
