3) targets 每次打开都重新请求（不缓存）—— Network 证明
================================================================================
操作：清空请求日志 → 打开弹窗 → 取消 → 再打开弹窗

  [42888.44] GET http://localhost/api/v1/notifications/targets (XHR) 200   <- 第 1 次打开
  [42888.45] GET http://localhost/api/v1/notifications/targets (XHR) 200   <- 第 2 打开

即「打开 N 次 = N 个 targets 请求」，无任何本地缓存 / memo。

4) 交互项核对
================================================================================
✅ 目标类型四选一（指定商家 / 指定门店 / 全部附属商家 / 全部门店）
✅ 指定类显示多选下拉（门店按商家分组 + 编码后缀）；ALL_* 隐藏选择器
✅ 切换目标类型自动清空已选（避免把门店 id 当商家 id 提交）
✅ 标题必填 ≤50；内容必填 ≤500；类型/级别下拉（默认 系统通知/普通）
✅ 发送预告实时显示接收方数量
✅ 提交中按钮 loading 防重复点击（submitting 期间禁用表单与关闭）
✅ 取消/关闭：空表单直接关；有内容弹「确认放弃填写？」；X/ESC 同样走 before-close
✅ 提交成功：ElMessage + 关弹窗 + 刷新当前 Tab 列表 + 同步未读数 store
✅ 后端契约：targetType 用后端枚举 MERCHANT/STORE/ALL_MERCHANTS/ALL_STORES（单数）；
   ALL_* 时 targetIds 传空数组（后端对 ALL_* 且 targetIds 非空会 400 NOTIFICATION_TARGET_INVALID）
✅ 无 mock：全部请求打到 /api/v1/*
